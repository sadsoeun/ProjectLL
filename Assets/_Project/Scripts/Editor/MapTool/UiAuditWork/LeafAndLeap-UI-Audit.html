LEAF & LEAP · UI 전수 점검

새 그림보다 공통 규격과 정보 위계 정리가 먼저 필요합니다.

2026-11-13 · 개선 전 점검 · 게임 UI/씬/프리팹 수정 없음 · 타이틀 호흡 OFF 유지

현재 6개 흐름 씬, 15개 스테이지 씬, 공용 팝업 2종, 런타임 생성 UI와 관련 코드를 확인했습니다. 스테이지 씬 자체에는 uGUI RectTransform이 없고 공용 InGame 화면을 함께 로드합니다. 현재 존재하는 W1~W3 스테이지를 대상으로 했으며 W4~W5의 실제 플레이 화면은 이번 점검 범위에 포함되지 않습니다.

이번 결과는 현재 코드·실제 씬/프리팹 좌표·기존 검증 이미지에 기반합니다. 모든 화면을 이번 턴에 새로 플레이하거나 렌더한 것은 아닙니다. 확인된 구조와 추가 실행 검증이 필요한 항목을 아래에 구분했습니다.

작업 우선순위

  1. 사용성 문제: 언어 선택 겹침 → 보스 UI 모달 정렬 → 저장 실패 안내.
  2. 공통 컴포넌트: 패널·글자·버튼·선택 상태 규격 → 설정창·인게임 일시정지·확인 팝업.
  3. 정보 전달: 결과·게임오버 목적지 문구 → 수집 성과 → HUD·준비/사망 안내.
  4. 마감: 타이틀 주 행동 강조 → 로딩 정보 → 컷인 세부 스타일. 시작 로고는 유지.

P1: 사용에 직접 영향 · P2: 가독성/일관성 개선 · P3: 후순위 마감. 등급은 이 프로젝트 안의 작업 우선순위입니다.

유지할 디자인

검정 패널·크림 본문·금빛 포인트, 승인된 얼굴과 코인 아이콘, 현재 셀식 타이틀 일러스트와 로고, 클리어 삼각 장식의 상향 이동 및 초수 표시. 특수 수집품·보스 체력의 의미색까지 전부 금색으로 바꾸지는 않습니다.

적용 후 검증 기준

  • 1280×720 / 1920×1080 / 2560×1080 / 1024×768에서 버튼 겹침·잘림·최소 글자 크기 확인.
  • 한국어·영어·중국어·일본어·스페인어에서 가장 긴 제목과 문장 확인.
  • 마우스·키보드·게임패드로 열기 → 설정 → 확인 → 취소 → 원래 버튼 포커스 복귀 확인.
  • 보스전 일시정지·게임오버·클리어에서 체력바가 메뉴 위에 남지 않는지 실제 재현.
  • 세이브 있음/없음·잠긴 스테이지·긴 클리어 시간·수집 0/3·3/3 및 저장 실패 상태 확인.
  • 새 테스트나 수정은 다음 구현 단계에서 수행. 이번 점검은 플레이어 저장 데이터에 변경을 가하지 않음.
