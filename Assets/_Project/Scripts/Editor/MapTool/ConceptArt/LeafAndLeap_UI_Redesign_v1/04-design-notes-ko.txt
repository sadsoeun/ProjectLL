LEAF & LEAP UI 개선 시안 v1

제작: built-in image_gen. 수치·플레이 장면은 예시이며 실제 플레이 캡처가 아니다.
참조: 프로젝트 내 타이틀·설정·클리어 검증 이미지, GoldUiTheme.cs, SettingsPopup.cs, WorldMapController.cs.
확인 범위는 저장된 검증 이미지와 현재 코드이며 이번 작업에서 새 실행 캡처를 촬영하지 않았다.

진단
GoldUiTheme에서 글자를 일괄 Cream으로, 버튼을 같은 스타일로 처리하여 중요도 구분이 약하다.
HUD는 글자 위치를 지정하지만 각 정보를 받치는 공통 패널 처리가 보이지 않는다.
설정 캡처는 비슷한 언어 버튼을 나열하고 볼륨 수치를 표시하지 않아 현재 값을 비교하기 어렵다.
타이틀 버튼이 모두 같은 형태여서 이어하기 등 주 행동의 우선순위가 약하다.

개선 원칙
1. 색의 역할: 패널 #132C29, 보조 면 #203C36, 본문 #F6F1E5, 보조 글자 #B9C9BD,
   강조 #D9B76B. 금색은 주 행동·선택 상태·상징에 사용한다.
2. 형태: 작은 모서리 컷과 얇은 테두리를 공통 컴포넌트로 사용한다.
3. 위계: 제목/핵심 숫자/설명 크기를 분리한다. 모든 텍스트를 같은 크기나 금색으로 두지 않는다.
4. 상태: 선택은 채움+아이콘, 잠김은 잠금 아이콘+설명, 켜짐/꺼짐은 위치+문자.
5. 가독성: 배경이 밝아도 글자가 읽히도록 HUD 패널 불투명도를 유지한다.
6. 글자와 숫자를 이미지에 굽지 않는다. 구현 시 로컬라이즈 가능한 텍스트와 재사용 아이콘으로 분리한다.

화면별
타이틀: 기존 왼쪽 메뉴·오른쪽 캐릭터 구도와 LEAF & LEAP 명칭 유지.
저장 데이터가 있을 때 이어하기만 주 버튼, 없을 때 새로 시작을 주 버튼으로 한다.
월드맵: 선택 스테이지의 이름·상태·최고 기록·수집품·입장을 한 카드로 모은다.
전체 지도에서 선택 노드에 집중한다. 개요의 노드 수와 경로는 레이아웃 예시이며 실제 25개 노드 데이터를 대체하지 않는다.
HUD: 좌측 잔여 목숨/코인, 중앙 스테이지/수집품, 우측 시간/일시정지.
생명 아이콘 ×3은 HP가 아닌 목숨 수다. 수집품 잎 아이콘은 통일 디자인 제안으로 실제 아이템 아트와 매칭해야 한다.
클리어: 축하 애니메이션 뒤 삼각형이 위로 이동하고 아래에 기록/수집품/다음 행동을 노출한다.
시안은 최종 정지 상태다. 최고 기록 갱신 배지는 실제 갱신 시에만 보인다.
마지막 스테이지에서는 다음 스테이지 대신 적절한 완료/월드맵 버튼을 사용한다.
설정: 언어는 선택값을 보여주는 드롭다운, 볼륨은 슬라이더+수치, 토글은 켜짐/꺼짐 문자.
닫기/완료 시 저장하는 기존 동작에 맞춰 저장 안내를 둔다. 메뉴 구조 변경은 아직 구현되지 않았다.

해상도 및 모션 구현 제안
1920x1080 기준 안전 여백 32~48px, 본문 28~32px, 주요 숫자 40~48px를 출발점으로 테스트한다.
고정 폭으로 화면을 늘리지 말고 앵커와 레이아웃 그룹을 사용한다.
16:9, 16:10, 21:9, 1280x720에서 긴 번역문·포커스·숫자 폭을 점검한다.
작은 화면은 패널 간 간격과 여백을 줄이고 필요 시 줄을 재배치한다. 텍스트 전체를 무작정 축소하지 않는다.
배경 일러스트는 비율을 유지하고 크롭하되 메뉴/캐릭터 중요 영역을 확보한다.
버튼 반응 0.12~0.18s, 팝업 0.18~0.25s 정도의 짧은 이동/페이드 제안.
클리어 상징 이동 뒤 기록은 빠르게 나타나게 하고 반복 플레이에서 연출 단축을 고려한다.
수치는 디자인 제안이며 실제 가독성·키보드/패드 탐색·반응형 동작 검증은 적용 단계에서 수행한다.

이번 산출물은 디자인 PNG와 명세다. 기존 씬·프리팹·스크립트는 수정하지 않았다.
