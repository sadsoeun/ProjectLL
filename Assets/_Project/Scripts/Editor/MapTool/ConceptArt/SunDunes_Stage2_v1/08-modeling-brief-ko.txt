2. 원본 이미지에서 이어받은 디자인
황금빛 사암 절벽, 밝고 평평한 모래 상판, 청록색 오아시스, 단순한 선인장과 야자수, 계단식 신전.
기존 블렌더 월드맵의 두툼하고 단순한 실루엣을 실제 플레이 스테이지용 모듈로 확장한다.
초원/설원/용암 테마는 섞지 않는다. 게임 타이틀이나 HAMZTER 로고를 변경하는 작업은 포함하지 않는다.
중간 채도의 따뜻한 모래색을 주조로 하고 청록 물·유물, 초록 식생, 적갈색 천을 포인트로 쓴다.
권장 색상: 모래 #F5D58A / 사암 #D99545 / 사암 음영 #AA663D /
물 #42C6CB / 식생 #73A642 / 천 #B65336 / 유물 코어 #71DDD1.
이 값은 제작용 제안이며 이미지에서 정확히 추출한 색상은 아니다.

3. 크기·좌표·카메라
기준 캐릭터 키 1m를 가정한 신규 아트 규격이다. 실제 캐릭터·점프 성능에 맞춰 최종 배율을 확인한다.
크기는 가로 X × 깊이 Y × 높이 Z, 단위 m, Blender 기준.
Blender: X=좌우 진행, Y=스테이지 깊이, Z=위. 카메라는 Y 음수 쪽에서 바라본다.
Unity: X=좌우, Y=위, Z=깊이. 내보내기 후 1m 큐브로 축과 배율을 확인한다.
플레이 바닥 깊이 기본 2m, 기본 스냅 1m, 세부 스냅 0.25m.
원화의 FRONT는 해당 에셋의 정면, SIDE는 측면이다. 몬스터 리깅은 몸의 로컬 정면을 먼저 통일한다.
원경 배치 시작값: Blender Y +12~25m 중경 / +35~70m 원경 / +80~120m 최원경.
원경 시트에 그려진 Z -100~-1200 등은 생성 이미지의 도식 표기이며 실제 제작 수치로 사용하지 않는다.
원경의 크기와 간격은 카메라 투영에 맞춰 조정한다. 3D 오브젝트이므로 이동 카메라에서 깊이와 옆면이 보여야 한다.

4. 모델링 원칙
원화는 설계 참고이며 CAD 도면이 아니다. 서로 다른 뷰에서 작은 형태·치수 차이가 나면 이 명세와 CSV의 수치를 우선한다.
전체 실루엣 → 큰 색면 → 필요한 관절/구동 부품 → UV 순으로 작업한다.
원경도 닫힌 입체 메시로 제작한다. 원경을 한 장의 이미지 평면으로 대체하지 않는다.
Flat 또는 제한된 smooth shading. 1~2단 bevel만 사용하고 사암의 층을 얕은 면 분할로 표현한다.
텍스처에 빛·그림자를 과하게 고정하지 않는다. 큰 색상 팔레트 또는 단순 아틀라스로 재질을 공유한다.
CSV의 triangles는 렌더 메시 1종 기준 초기 목표이며 성능 측정 결과가 아니다. 실제 카메라 거리와 타깃 기기에서 조정한다.
피벗: 바닥은 스냅용 모서리, 일반 프랍은 바닥 중심, 몬스터는 접지 중심, 기믹은 고정부와 가동부를 분리.
Collision은 간단한 box/capsule/convex 조합을 별도 오브젝트 COL_로 만든다.
시각 메시의 요철을 그대로 플레이어 충돌체로 사용하지 않는다.
원경은 기본 충돌 없음. 이펙트 메시 자체에는 충돌 판정을 넣지 않는다.
이름: SD_G01_Ground_Straight / SD_M01_CactusWalker / SD_P11_SunSwitch처럼 ID를 유지.
컬렉션: SD_Ground, SD_Background, SD_Monsters, SD_Props, SD_FX, SD_Colliders.
원경 LOD1 목표는 LOD0의 약 50%, LOD2 약 20~30%로 시작하되 실루엣을 우선한다.

5. 지형 모듈 보완 기준
G01 평평한 모래 상판과 사암 측면. 인접 모듈의 접합 면은 평면을 유지한다.
G03 안쪽 코너: 2×2m 정사각형에서 1×1m 사분면 하나를 뺀 L자 평면. 오목한 안쪽 모서리 연결용.
G04 바깥 코너: 2×2m 발판의 바깥 한 모서리를 0.5m 사선으로 깎은 볼록 코너. G03과 같은 L자로 만들지 않는다.
G05 경사: 진행 길이 2m, 깊이 2m, 높이차 1m. 물리 경사는 별도 단순 경사면.
G06 계단: 총 높이 1m, 3단. 부드러운 이동을 위해 계단 위에 보이지 않는 경사 충돌체를 권장한다.
G07/G08의 0.3m는 상판 두께다. 원화에 보이는 장식용 바위 밑면은 추가 깊이로 만들 수 있으나 착지면 높이는 동일하다.
G08은 4개 큰 조각, 낙하 전 경고 상태, 복구 상태를 고려한다.
G09 절벽은 위·아래 반복 연결되도록 경계 높이와 폭을 맞춘다.
G10 오아시스 테두리와 물은 반드시 별도 메시. 물면이 테두리 상단보다 0.1m 낮게 위치한다.
컨셉샷의 폭포는 G09 뒤쪽 절벽 + P03 암석 + 별도 얇은 물 리본의 조합으로 확장 가능한 장식 예시다.

6. 몬스터 8종과 역할
M01 선인장 워커: 0.8m, 느린 순찰 + 짧은 도약 + 씨앗 투사체. 몸/팔2/발2/꽃을 분리.
M02 태양 풍뎅이: 높이 0.55m, 6개의 다리(좌우 3쌍), 더듬이2. 등껍질 방어 후 구르기 돌진. 다리는 구르기 때 숨기거나 접는다.
M03 사구 전갈: 몸 높이 0.65m, 꼬리 포함 최대 약 1.1m. 보행 다리 8개(좌우 4쌍), 집게2, 꼬리1을 확정한다.
시트에서는 다리가 겹쳐 보일 수 있으므로 보이는 개수만 따라 만들지 않는다. 꼬리 관절은 5~6개.
M04 모래 슬라임: 0.5m, 잠복 후 튀어나옴. 몸과 머리 위 사암 조각을 분리; 몸은 scale 또는 shape key로 squash/stretch.
M05 모래벌레: 노출 높이 1.2m, 전체 길이 약 2.4m. 머리+몸통 링5, 위아래 둔한 이빨 총4개. 잠복 예고 후 수직 출현.
M06 황혼 박쥐: 몸 높이 0.6m, 날개 폭 1.4m. 날개2/귀2/발2. 정찰 비행 후 사선 급강하.
M07 붕대 수호자: 1.2m, 느린 근접 펀치. 팔2/다리2, 단순한 손, 넓은 붕대 띠; 가는 붕대 실을 만들지 않는다.
M08 사암 골렘: 1.8m, 느린 지면 강타. 머리/몸통/상완2/전완2/손2/발2 및 청록 코어 분리.
M08은 이 팩의 중형 정예 적이며 별도의 스테이지 보스로 확정한 것은 아니다.
공통 기본 클립: Idle, Move, Anticipate, Attack, Hit, Defeat. M02 Roll, M04/M05 Burrow, M06 Fly 추가.
몬스터별 크기 수치를 우선한다. 시트 하단 그림의 상대 크기는 엄밀한 축척도가 아니다.

7. 프랍과 기믹
P01~P10은 자연물/유적 장식이며 P07 다리는 실제 통행 가능 오브젝트로도 사용.
P05 문과 P06 신전은 실루엣과 포인트 색을 공유하되 서로 다른 에셋으로 제작.
P08 항아리 파괴편은 원본과 같은 부피에서 4개 정도의 큰 덩어리로 분할.
P09 천과 봉 분리. 천은 2~3개의 세로 구간만 두어 작은 바람 변형이 가능하게 만든다.
P10 화로의 불은 FX 전용; 고정 모델에 광원이 포함된 이미지를 붙이지 않는다.
P11 발판 고정부/가동판/문양 분리. 가동판 높이 이동량 0.08m.
P12 가시 3개/하우징 분리. 예고→상승→유지→하강 단계를 두고 피해 판정은 활성 구간에만 연결.
식생과 기둥은 카메라에서 착지 지점과 적의 공격 예고를 가리지 않도록 주로 뒤쪽에 배치.

8. 이펙트 제작 기준
07-effects.png는 시간 흐름을 설명하는 원화이며 그대로 사용하는 스프라이트 아틀라스가 아니다.
실사용 파티클 텍스처는 별도 투명 배경으로 제작하고, 배경색·문자·패널 테두리를 포함하지 않는다.
Blender에서는 돌 파편/모래 둔덕/링/리본/물 왕관 등 재사용 메시를 만들고 Unity에서 시간·투명도·방출을 구성.
FX01 발자국: 총 0.2~0.45초, 3~6 작은 입자, 발 접지 이벤트.
FX02 타격: 총 0.35~0.7초, 파편4~6 + 짧은 충격 링, M08 강타·항아리 파괴에 재사용.
FX03 잠복 출현: 예고 0.5초 이상 + 분출 0.25초 + 잔여 모래 0.4초, 공격 판정과 예고를 분리.
FX04 바람: 2~4초 간헐 반복, 낮은 알파 리본1~3개, 플레이 경로의 가시성을 유지.
FX05 낙사: 예고 누출 0.4초 → 본류 → 0.3초 잔여물, G08 붕괴와 유적 장식에 사용.
FX06 유사: 2초 이상 느린 반복, 바닥 원반과 링. 이동 감속/흡입 여부는 게임 로직에서 별도 결정.
FX07 물: 총 0.5~0.9초, 물 왕관 + 물방울 + 넓어지는 수면 링.
FX08 문 활성화: 예고 0.3초 → 확산 0.5초 → 잔광 0.7초. P11 작동 후 P05/P06 문양에서 발생.
강한 섬광이나 불투명 먼지로 플레이어/가시/착지점을 가리지 않는다.

9. 스테이지 조합 제안
2-1 사막 입구: G01/G02/G05, P01/P02/P03, M01/M04. 기본 점프와 모래 적 소개.
2-2 오아시스 유적: G06/G07/G10, P04/P07/P08, M02/M06. 물가·교량·상하 경로.
2-3 무너진 협곡: G08/G09, P12, M03/M05. 낙하 발판과 지면 출현 예고.
2-4 태양 신전: P05/P06/P09/P10/P11, M07/M08. 스위치와 정예 적 결합.
2-B는 기존 게임의 보스 설계와 연동하여 별도 확정한다. 이번 이미지 세트에는 확정 보스 전용 원화가 없다.
위 구간명과 배치는 신규 제안이다. 실제 맵툴 기능이나 점프 물리를 분석·검증한 완성 레벨이 아니다.

10. 납품 및 검수
모델별 원점/단위/스케일 확인 → 정면/측면/후면 스크린샷 → 그레이박스 레벨 조합 → 재질 확인 → 충돌체 확인.
원경 옆면·후면 누락, 발판 경계 틈, 관절 분리 누락, 몬스터 다리 수, 가시가 하우징을 뚫는 문제를 검사.
.blend 원본, 개별 .fbx 또는 프로젝트 규칙의 포맷, 공유 재질/텍스처, 정면·측면·후면 미리보기를 제공.
이 요청은 원화 제작 단계다. 기존 Unity 씬이나 블렌더 파일을 이번 작업에서 변경하지 않았다.
