아래 폴더의 SUN DUNES 원화 시트와 제작 명세를 기준으로 Blender MCP를 이용해 사막 플랫포머 에셋을 제작해줘.

먼저 08-modeling-brief-ko.txt와 10-asset-manifest.csv를 읽고, 해당 에셋의 PNG 시트를 확인해.
01-stage-keyart.png는 스타일·구성 예시다. 이를 하나의 평면 이미지나 통짜 모델로 만들지 말고 ID별 개별 에셋을 만들어줘.
시트의 글자/치수/사시도에 모순이 있으면 제작 명세와 CSV를 우선해. 특히 G03/G04 코너 형태, 몬스터 다리 수, 원경 깊이 수치를 명세대로 적용해.
기준은 1m 캐릭터, Blender X 진행/Y 깊이/Z 위. 게임의 실제 캐릭터 크기를 확인할 수 있다면 먼저 배율만 맞춰줘.

작업 순서:
1) 별도 .blend 원본을 준비하고 1m 기준 큐브와 그레이박스 발판을 배치.
2) G01, G02, G05, G06, G07부터 제작해 접합과 플레이 바닥 깊이 2m를 검수.
3) G03/G04/G08/G09/G10을 추가하고 바닥 키트의 10종을 완성.
4) P01~P12를 제작. 다리/문/스위치/가시는 고정부와 움직이는 부품을 분리.
5) B01~B06 원경을 완전한 입체 메시로 제작. 사구 밑면과 아치 두께를 확인하고 LOD 추가.
6) M01~M08의 정면·측면·후면과 관절 구성을 검수하고 중립 포즈에서 리깅 가능한 구조로 제작.
7) FX01~FX08에서 필요한 재사용 메시만 Blender로 제작. 시간 연출·입자 방출·투명도는 별도 Unity 설정으로 정리.
8) 컬렉션·오브젝트 이름·피벗·단위·COL_ 충돌체를 정리하고 개별 에셋 내보내기.

원본 디자인의 큰 색면과 실루엣을 유지해. 재질은 팔레트 공유를 우선하고 원경에 사진이나 빌보드를 사용하지 마.
상판은 평평하고 접합 경계는 정확하게 유지해. 시각적인 바위 요철과 플레이 충돌체는 구분해.
손/다리/꼬리 개수는 명세를 따르고, 움직임을 위해 필요한 부품은 하나로 합치지 마.
권장 triangles는 목표치이므로 실루엣을 유지하며 조정하고 최종 실제 수치를 알려줘.
각 단계 완료 시 .blend 저장과 정면/측면/후면 미리보기로 검수해. 기존 게임 씬이나 기존 월드맵 원본을 덮어쓰지 말고 새 파일로 납품해.

납품: .blend 원본, ID별 모델 파일, 공유 재질/텍스처, 피벗과 충돌체 구성, 실제 삼각형 수, 미리보기.
