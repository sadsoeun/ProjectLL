2026-11-13. 게임 적용 전 정지 이미지 시안.
사용자 피드백: 초록색 패널을 제거하고 현재 미감을 유지하며 가독성만 개선.
원본 참조: 타이틀 cel-title-16x9.png, 설정 settings-02-focus.png, 클리어 clear-2.35.png.
이전 v1의 초록 패널/둥근 버튼/드롭다운 제안은 이번 방향에 적용하지 않는다.

유지: 거의 검정인 배경, 얇은 금색 사각 테두리, 크림색 글자, 다이아 포인트, 클리어 삼각형.
타이틀 왼쪽 메뉴와 오른쪽 캐릭터 구성 유지. 기존 다섯 언어 버튼과 체크박스 유지.
개선:
- 핵심 숫자의 크기와 굵기를 키우고 작은 설명과 위계를 구분.
- HUD 글자 뒤에 작은 중성 검정 받침을 두어 밝은 배경과 분리.
- 글자/숫자 기준선을 정렬하고 일정한 행간과 안쪽 여백 사용.
- 선택 버튼만 옅은 금갈색 채움과 밝은 글자/다이아 표시로 구분.
- 볼륨 수치, 빈 슬라이더 구간, 체크박스의 켜짐/꺼짐 명시.
- 클리어 삼각형을 위로 이동한 뒤 기록을 아래에 크게 노출.

색 제안: 배경 #0C0D10, 본문 #FFF1D2, 테두리 #C9A66A, 선택면 #30271A.
패널은 중성 검정으로 하고 초록색은 게임 배경에만 사용.
이미지는 배치·색·위계 제안이며 재사용 가능한 UI 에셋이나 실제 실행 캡처가 아니다.
기록, 목숨, 수집품 수치는 예시. 지도 경로와 스테이지 아트는 시안용이다.
텍스트는 적용 시 로컬라이즈 가능한 실제 UI 컴포넌트로 구성해야 한다.
삼각형 이동 애니메이션은 이 정지 이미지에 구현되어 있지 않다.
기존 씬/스크립트/프리팹은 변경하지 않았다.
제작 방식: built-in image_gen. 최종 프롬프트는 동봉 JSON 참조.
