Leaf & Leap 인트로 게임 적용 — 2026-11-16

최신 변경: 로고 연속 이동·배경 교차 전환을 추가했다. Handoff/적용기록.txt 참고.
현재 재적용 스크립트는 install_handoff.ps1이며, 아래 내용은 초기 시작 흐름 기록이다.

최종 시작 순서: Unity 스플래시 → HAMZTER 로고 → 최초 언어 선택 → 약 85초 인트로 → 타이틀.
언어를 이미 선택했으면 언어 선택 화면은 생략하고 저장된 언어로 인트로를 재생한다.
타이틀의 새로 시작 → 저장 생성 → 로딩 → 월드맵. 이어하기도 인트로 없이 월드맵으로 이동한다.
월드맵에서 타이틀로 돌아오는 경우 인트로를 반복하지 않는다.
에디터에서 타이틀 씬을 직접 재생하면 시작 순서는 건너뛴다. 01_Logo 씬에서 실행해야 전체 흐름을 볼 수 있다.
Unity 엔진 스플래시는 빌드한 게임에서 표시되며, 현재 설정은 활성화 상태다.
영상 및 The Golden Leaf 음악은 공통으로 사용한다.
자막 14개, 엔딩 문구, 준비 문구, 건너뛰기는 게임 언어에 맞춰 표시한다.
지원 언어: 한국어, 영어, 일본어, 중국어 간체, 스페인어.
글꼴: 기존 Noto Sans. 긴 자막은 줄바꿈/축소, 영상은 비율 유지.
Esc / 패드 취소·시작 / 화면 건너뛰기 버튼을 지원한다.
전체 볼륨 및 BGM 볼륨을 따른다. 영상 준비 실패 시 타이틀로 진행한다.
종료·건너뛰기는 0.45초 화면/음악 페이드 후 타이틀로 이동한다.
타이틀 배경의 페이드가 끝난 후 기존 로고/메뉴 등장 애니메이션을 시작한다.
로고 씬에는 EventSystem이 없으므로 필요한 경우 인트로 전용 입력 객체를 생성하고 씬 전환 시 함께 정리한다.
영상은 H.264 Baseline으로 재인코딩했다. 오디오 스트림의 MD5는 원본과 동일하다.
타이틀 호흡은 꺼둔 상태를 유지했다. Live2D 리깅과 기존 저장 데이터는 수정하지 않았다.

검증 범위
- 전체 프로젝트 응답 파일을 이용한 런타임/에디터 C# 컴파일 통과.
- 별도 Unity 프로젝트에서 실제 영상 준비·디코딩 및 캡처 확인.
- 실제 자막 UI: 5개 언어 × 4개 해상도 × 14개 자막 영역 검사 통과.
  해상도: 1920×1080, 1280×720, 1024×768, 2560×1080.
- 볼륨 변경, 재생 중 언어 변경, 건너뛰기, 완료 콜백 중복 방지 확인.
- 재생 오류 처리 경로는 오류 호출을 주입해 확인했다.
- 테스트 정리 시 편집 모드의 RenderTexture 해제 오류를 수정 후 재검증했다.
- 게임에 설치한 코드와 영상의 해시가 검증한 파일과 일치한다.
- 초기 자막 배치 검증은 서비스 대역을 사용했다.
- 최종 흐름 검증은 게임 전체 복사본에서 실제 씬과 실제 서비스를 사용하여 Play Mode로 수행했다.
  로고 → 최초 언어 선택 → 실제 영상 85초 완주 → 타이틀 → 새로 시작 → 로딩 → 월드맵 통과.
  타이틀 재진입 → 이어하기 → 월드맵 통과.
  저장된 언어를 다시 로드한 로고 경로 → 인트로 → 가상 마우스 버튼 클릭 → 페이드 → 타이틀 통과.
  별도 로고 경로 → 인트로 → 가상 키보드 Esc → 타이틀 통과.
  UI 레이캐스트, 화면/음악 중간 페이드 값, 입력 잠금 해제, 중복 완료 방지도 확인했다.
  최종 실행 중 게임 오류 0건. Unity 종료 코드 0.
  모든 적용 소스 7개는 검증 복사본과 해시가 일치한다.
- 검증 복사본은 별도의 회사/제품명으로 저장 경로를 분리했다. 원본 사용자 저장은 건드리지 않았다.
- 컴퓨터 화면 조작은 하지 않았다. 숨긴 Unity 내부에만 가상 입력 이벤트를 전달했다.
- 엔진 Unity 스플래시는 설정만 확인했다. 실제 빌드 플레이어 스플래시 렌더는 이번 검증 범위 밖이다.
- WindowsMediaFoundation 색상 정보 경고는 남아 있다. 타임스탬프 경고는 Baseline 변환 후 나타나지 않았다.
