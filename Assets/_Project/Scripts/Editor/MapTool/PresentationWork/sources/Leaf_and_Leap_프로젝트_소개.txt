1. 프로젝트 개요 
Leaf & Leap은 유니티짱이 초원에서 용암 요새까지 다섯 개의 월드를 달리고 뛰어넘는 3D 
횡스크롤 플랫포머입니다. 월드는 3D로 표현하지만 조작은 좌우 이동과 점프에 집중해, 누구나 
바로 이해할 수 있는 조작과 분명한 점프·착지 감각을 목표로 합니다. 고전 플랫포머의 이동 · 장애물 
배치 · 탐험과 보상 구조를 참고하되, 캐릭터 · 맵 · 음원 · 시각 자산은 모두 자체 제작했습니다. 
항목 내용 
장르 3D 횡스크롤 액션 플랫포머 (사이드 뷰 카메라) 
엔진 / 렌더링 Unity 6.3 LTS (6000.3.6f1) / Universal Render Pipeline, 카툰 셰이딩

핵심 조작과 규칙 
• 이동 · 달리기 · 점프: 좌우 이동, 달리기 버튼으로 가속, 누르는 길이에 따라 높이가 달라지는 
가변 점프. 
• 밟기 공격: 몬스터와 기절한 보스의 머리를 밟아 처치합니다. 일부 몬스터(예: 흑요석 
아르마딜로)는 밟을 수 없습니다. 
• 회피와 퍼펙트 회피: 앞으로 짧게 대시하는 회피. 몬스터·보스 공격을 회피 중에 받으면 퍼펙트 
회피가 되어 2초간 세계가 흑백으로 멈추고, 플레이어만 움직일 수 있습니다. 
• 수집과 진행: 코인, 스테이지마다 특별 수집품 3개, 체크포인트, 목숨, 클리어 시간 기록과 
신기록 표시.

4. 몬스터 AI 패턴 
몬스터는 Unity Behavior 그래프 기반의 공통 AI 위에 데이터 테이블(MonsterTable)로 능력치와 
공격 방식을 지정합니다. 같은 AI 구조를 공유하므로 새 몬스터는 모델과 데이터만으로 추가할 수 
있습니다. 
구분 동작 
순찰 (Patrol) 정해진 범위를 왕복하고, 벽이나 낭떠러지 앞에서 잠시 멈췄다 돌아섭니다. 
추격 (Chase) 시야에 플레이어가 들어오면 추격하고, 놓치면 일정 시간 뒤 순찰 위치로 복귀합니다. 
공격 6종 돌진(charge) · 내려찍기(slam) · 근접(melee) · 덮치기(lunge) · 도약(leap) · 원거리 
발사(shoot). 모든 공격은 예비 동작으로 미리 알려줍니다. 
엘리트 체력이 높은 골렘류(사암 · 얼음 · 현무암 골렘). 여러 번 밟아야 처치됩니다. 
 
월드 몬스터

5. 보스 5종 
모든 보스는 같은 규칙을 따릅니다. 보스가 공격을 마치면 잠시 기절하고, 그때 머리를 밟아야만 
피해를 줄 수 있습니다. 체력이 줄수록 3단계 페이즈로 넘어가며, 공격 조합이 늘고 대기 시간이 
짧아집니다. 
보스 월드 주요 패턴 
새싹왕 W1 돌진 → 도토리 낙하 → 연속 돌진 
태양 수호자 W2 내려찍기 충격파 → 바위 낙하 
서리 매머드 W3 돌진 · 얼음 가시 충격파 · 고드름 낙하 
산호 소라왕 W4 껍데기 돌진 · 집게 충격파 · 산호 낙하 
용암 갑룡 W5 (최종) 돌진 · 마그마 충격파 · 불덩이 낙하 · 용암 순차 분출(전용 기믹) 
 
최종 보스 전용 기믹: 용암 순차 분출 
용암 갑룡이 기를 모았다가 뿔을 바닥에 꽂으면, 보스 쪽에서 바깥쪽으로 용암 기둥이 한 칸씩 
순서대로 솟아오릅니다. 각 칸은 바닥 균열 경고 후 잠깐만 위험하므로, 막 분출이 끝난 칸으로 
앞으로 걸어 들어가면 피할 수 있습니다. 타이밍이 어긋나도 회피(퍼펙트 회피)로 빠져나갈 수 
있습니다. 
  
새싹왕 돌진과 퍼펙트 회피 용암 갑룡의 용암 순차 분출

6. UI와 1차 폴리싱 
• 화면 흐름: 로고 → 언어 선택(첫 실행) → 타이틀 → 로딩 → 월드맵 → 스테이지. 모든 전환은 
페이드와 로딩 화면으로 연결됩니다. 
• 타이틀: Live2D로 움직이는 캐릭터 일러스트, 새로 시작 · 이어하기 · 설정 · 종료. 
• 월드맵: 노드를 따라 이동하며 스테이지 정보(최고 기록, 특별 수집품)를 확인하고 바로 
입장합니다. 
• HUD: 목숨 · 코인 · 스테이지명 · 특별 수집품 · 시간 · 일시정지 버튼. 보스전에서는 보스 체력 
바가 표시됩니다. 
• 일시정지 · 결과: 계속 · 다시 시작 · 설정 · 월드맵으로. 클리어하면 축하 연출 뒤 시간 · 코인 · 
수집품 · 신기록을 표시합니다. 
• 연출: 퍼펙트 회피 시간정지(흑백 + 째깍 효과음), 보스 기절 시 '지금이다!' 컷인, 월드별 하늘 · 
안개 · 배경 효과(불티, 용암 기포 등).

7. 제작 방식 
영역 방식 
레벨 디자인 JSON 스테이지 레이아웃 + 전용 맵 툴. 검증기가 점프 가능 높이, 체크포인트 간격, 
보스 아레나 등을 검사한 뒤 씬을 자동 빌드합니다. 
3D 아트 Blender(헤드리스 스크립트)로 모듈형 지형 · 소품 · 배경 · 몬스터 · 보스를 제작하고, 
전용 임포터가 프리팹 · LOD · 머티리얼을 구성합니다. 
셰이더 URP용 자체 카툰 셰이더와 환경 셰이더(용암 바다, 하늘, 파티클). 
AI Unity Behavior 그래프 + MonsterTable 데이터 기반 몬스터, 공통 BossController + 
보스별 데이터 에셋. 
현지화 5개 언어 문자열 테이블과 언어별 번들 폰트. 
AI 협업 기획 문서화, 코드 구현 · 리뷰, 에셋 제작 스크립트, 시연 영상 자동 연출, 본 소개서 
초안 작성에 AI(Claude)를 활용했습니다.

8. 검증 현황과 남은 과제 
• 자동 검증: 25개 스테이지 맵 검증 통과(오류 0), 컴파일 오류 없음, 보스 자동 전투 테스트(공격 
→ 기절 → 밟기 → 처치) 통과. 
• 시연 녹화: 영상은 무적 모드와 자동 입력으로 실제 게임을 플레이해 녹화했습니다. 사람이 직접 
하는 플레이 테스트와는 다릅니다. 
• 남은 확인: 최종 보스 용암 분출 타이밍, 신규 몬스터 4종의 실제 플레이 난이도, 월드별 난이도 
곡선은 사람의 플레이 테스트로 조정이 필요합니다. 
다음 단계 
• 사람이 직접 하는 플레이 테스트로 난이도와 보스 패턴 타이밍 조정 
• 코요테 타임과 점프 입력 버퍼 도입 검토 
• 사운드 보강(월드별 BGM, 보스 전용 효과음)과 2차 비주얼 폴리싱 
• 목표 플랫폼과 성능 예산 확정, 빌드 최적화
