

Leaf & Leap 개발 가이드




Leaf & Leap 개발 기록
Claude Code × Unity 작업 가이드

Claude Code와 함께 Unity 3D 횡스크롤 플랫포머를 만든 과정을 날짜별 단계로 정리했습니다. 환경 구축부터 2주차 과제 영상, BGM과 효과음 적용까지 담았습니다.

2026-10-29 ~ 11-06작업일 6일 · 프롬프트 84개Unity 6.3 LTS (6000.3.6f1) · URPCoplay MCPBlender 5.2 · Blender MCPSD 유니티짱



개요



최종 결과: 게임 이름은 Leaf & Leap입니다. 씬 구성은 로고 → 언어 선택 → 타이틀 → 로딩 → 월드맵 → 인게임입니다. 월드맵에는 5개 지역 25개 노드가 하나의 길로 이어져 있고, 그중 10개 스테이지를 만들었습니다(1지역 1-1~1-4와 1-B 보스, 2지역 사막 2-1~2-4와 2-B 보스). Behavior 그래프로 만든 몬스터 AI, 맵툴, 툰 셰이더 아트, BGM, 효과음 19종이 들어가 있고, 과제 제출용 2분 44초 영상 초안도 있습니다.

이 가이드를 읽는 법: 날짜마다 한 일을 STEP으로 묶었습니다. 각 단계는 목적 → 결과 → 주의·팁 → 실제로 쓴 프롬프트 순서입니다. 프롬프트 박스 오른쪽 위의 복사 버튼을 누르면 원문을 그대로 붙여 넣을 수 있습니다.

팁
“실제로 쓴 프롬프트”는 Claude Code에 직접 입력한 원문입니다. 한 글자도 바꾸지 않았고 오타와 띄어쓰기도 그대로 두었습니다. 붙여 넣은 텍스트에 붙은 <pasted_content> 표시도 기록에 남은 그대로입니다. 시각은 메시지를 보낸 시각이고, “작업 중 추가”는 이전 작업이 진행되는 동안 보낸 메시지입니다. 전체 원문은 맨 아래 부록에 시간순으로 다시 모았습니다.

주의
“결과”는 그때 Claude가 보고한 내용을 요약한 것입니다. 보고 당시 확인하지 못했다고 한 항목은 그대로 “미확인”으로 적었습니다. 대화 원문 전체(Claude 답변 포함)는 같은 폴더의 claude-sessions.html에 있습니다.
